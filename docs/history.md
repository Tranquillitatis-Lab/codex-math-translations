## 从原请求保留的关键表述

多次请求共同要求：“翻译后的版本应当贴近中文母语者语言，书写习惯”，允许润色和语序调整，“但是语义仍要和原文一致”。

FGA 与 SGA 4½ 请求进一步要求：发现命题有 gap、数学错误或疏漏，且能举出反例、补完条件或论证时，应加相应译者注。

SGA 会话随后把调度方式收紧为：以 token 效率为目标，由主 Agent 直接派发并接收译稿，不安排只做协调的 Agent。用户也明确选择不研究重建源文件的残缺内容，而是在翻译后提供缺失报告，自己寻找可补文本。

这些后续纠正已合入 [当前提示词](prompts.md)。各书早期翻译指引仍作为项目资料保留；实际运行遵守当前任务授权及仓库 `AGENTS.md`。

## 本次归并的边界

本次处理目录合并、缓存清理、维护脚本路径和文档，不重新翻译或重新判定既有数学补注。分册 PDF 沿用现有成品；SGA 原会话中断时的总本仅存本地归档，不发布为正式总本。
