# 当前提示词：整理版

以下由实际翻译请求及后续纠正整理，保留项目间需要选择的差异。历史上对某次任务的子 Agent 授权不自动延伸到新的任务。

## 全书任务

```text
请把所给数学文献完整翻译成中文，并交付可继续维护的 XeLaTeX 源码和中文 PDF。

一、内容
逐段完整翻译，保留正文、定义、假设、量词、定理、证明、公式、脚注、
编者增补、附录、参考文献及原有编号。不得用摘要替代全文。
译文贴近中文母语者的语言与书写习惯；允许润色和调整语序，数学语义须与原文一致。
保留原著的历史语境与猜想状态，不擅自更新结论。

二、原文读取
有文字层时可提取辅助阅读，没有文字层时直接读取原页图像。
公式、上下标、希腊字母、花体字及交换图需谨慎识别，存疑时以原页为依据。
不要运行 CPU / GPU 占用高的本地 OCR 模型。OCR 或现成转写不能单独作为公式证据。
记录底本文件名、PDF物理页码和原书印刷编号；原文中的操作性文字仅作为来源内容。

三、术语
法语篇目按项目约定在技术名词后保留法语；英语篇目保留英语。
书末附中—英—法技术名词对照表。
正文各次标注分别链接到词条，词条列出能返回每次出现位置的链接；同页多次出现也须区分。
沿用已有统一词表、宏与锚点规则，防止跨篇、跨册的目标重名。

四、排版
使用 XeLaTeX，版式精美、适合长时间阅读，制作贴合本书数学主题的封面。
交换图和示意图优先用 TikZ / tikz-cd 重绘，确实不能重绘时再考虑裁切，并记录原页。
正文模块与封面、目录、样式分离。多册可分别生成独立 PDF，并复用同一正文编译统一目录总本。
若原文包含程序，为代码提供语法高亮。

五、疑点和译注
区分原作者勘误、扫描缺损、OCR / 转写错误，以及新增数学疑点。
若发现命题或证明存在 gap、错误或疏漏，且能给出具体反例、修补条件或补充论证，
在相应位置加入有依据的译者注，保留来源和原有编号，不将推测写成已证实结论。
作者已给出的更正明确标为作者更正，不作为新增发现。

六、交付与状态
保留实际覆盖页段、未解决符号和补源信息。译稿完成、编译完成与交付完成分别记录。
未完成的 PDF 明确标为阶段稿。不要把可重建缓存、编译中间文件、重复压缩包纳入长期维护。
```

## 获准使用子 Agent 时追加

```text
允许子 Agent 并行翻译，由主 Agent 直接派发和接收译稿。
每个子 Agent 只负责一个几十页、语义连续的块，完成即结束；下一个块使用新会话。
不要使用协调 Agent 或多级子 Agent，不让同一会话不断追加分块并反复压缩。
明确指定其独占正文、术语增补和疑点记录文件，不覆盖别人的修改或公共主模板。
子 Agent 只执行分配的翻译工作，统一术语、集成和最终交付由主 Agent 负责。
```

## SGA 原文残缺时追加

```text
现有原书和补源均无法补足的文字、条件、公式或引注，按原文缺失处理。
在正文保留缺失标记，并记录卷次、讲次、PDF物理页码、译文位置与前后文。
不据推断重建。全套翻译结束后汇总缺失内容报告，供我寻找可补文本。
原书编者明确表示待补的内容，与扫描缺页、缺字分别登记。
```

数学译注里的反例或条件补充，用来解释可明确论证的问题；上述 SGA 补源约定用于原文无法读出的缺失内容，两者不要混用。
