# Gap、勘误与补源

这里整理已有译稿和历史会话中的问题记录。每项讨论都应回到所指原文、版本与译注；后续复核意见可以继续修订这些记录。

## 分类

| 类型 | 处理原则 | 现有材料 |
| --- | --- | --- |
| 原著明确列出的勘误、编者待补 | 标明原作者或编者，不作为新增发现 | FGA 书前评论；SGA 各块报告 |
| OCR / 转写错误 | 依据原页恢复，不把辅助文本错误归于原著 | SGA 4½ `notes/` 中的转写纠错 |
| 数学陈述或证明疑点 | 给出原位置、具体理由、反例或可陈述的修补条件 | 下列实例及正文译注 |
| 源文件缺字、缺公式、缺引注 | 保留缺失标记与上下文，等待可读补源 | SGA `reports/missing-content.json` |
| 已补齐的缺页 | 保留补页来源，更新状态 | 自守形式第二册第 295 页 |

## 具体实例

### LNM 1553：定理 6.4 的正特征证明范围

[译者补注第 2 项](../books/arithmetic-algebraic-geometry/translator-notes.tex)记录：陈述涉及正特征基域，但所引平展上同调单射只覆盖 ℓ 不等于基域特征的初级挠元，后续指数有界论证又明确使用特征零。单靠这里的证明，正特征的全部范围，尤其 p 初级部分，尚不能推出。

补注区分了两种处理：若只采用书中给出的论证，限制到书中论证覆盖的特征零情形；若保留原陈述，需补充正特征证明。该项属于证明范围缺口，不能靠改一个符号解决。这批 29 项补注来自用户随后提供的勘误说明，来源原文保存在 [annotations](../books/arithmetic-algebraic-geometry/annotations/)。

### FGA：商构造的一处仿射性条件

[商概形一篇的记录，第 212-13 页段](../books/fga/notes/05-quotient.md)讨论：仅有 `fp₁ = fp₂` 与所写环层序列正合，不足以对任意预概形推出紧接着列出的商性质。

记录中的例子取 `X = P¹_k`、平凡关系 `R₁ = X`、两个投影均为恒等，以及结构态射 `f: X → Spec k`。环层条件成立，但该结构态射并不是平凡关系所要求的商。译注提出补充 `f` 仿射后，在仿射开集上应用前述结论再粘合。

同篇 6.1 与猜想 8.1 所涉的另一些更正来自 Grothendieck 原有评论，现有译稿已单独标示其作者来源。

### SGA 4½：紧支撑下标与迹公式

[第六篇前半的记录](../books/sga4-5/notes/06a.md)列出原书 184–185 页若干迹公式右端缺紧支撑下标 `c` 的问题。记录以有限域上的仿射直线常值层为例，比较点数 `q` 与普通上同调给出的迹 `1`，说明不能把两种上同调混用。

这些记录还保留了按扫描恢复转写误写的条目，两类问题分别列出。

### 不同来源的补充条件

现有译注还记录了以下例子，正文中保留更完整的条件和论证：

- [LNM 1553 补注第 22 项](../books/arithmetic-algebraic-geometry/translator-notes.tex)：范数比较的测度非退化条件；在 `P¹` 上取 Dirac 测度和在该点消失的非零截面，L² 范数为零而上确界范数非零。
- [同文件第 26 项](../books/arithmetic-algebraic-geometry/translator-notes.tex)：Hensel / Newton 引理的完备性；`Q` 配 7 进绝对值，`T²−2` 在初值 3 满足所列估计，根却不在 `Q` 中。
- [FGA Picard 性质一篇](../books/fga/notes/08-picard-properties.md)：正规与几何正规不能直接互换；记录给出非完美域上的具体曲线，并说明补充几何正规或基域完美后的处理。

## SGA 的补源状态

[机器可读清单](../books/sga/reports/missing-content.json)有 75 条记录，包含卷次、原 PDF 的 1 基页码、译文位置、上下文和分块报告。其中 `editorial_todo` 表示原书编者明示待补，和 `source_lacuna` 分开。

原会话中，用户明确选择先按原文缺失处理，由最终报告辅助寻找补充文本；不据上下文猜填公式、条件或引注。目前 JSON 清单已有保留，排版报告 PDF 的交付尚未完成。SGA 普通正文的“译稿完成”也不意味着这些来源缺损已经解决。
